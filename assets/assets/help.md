# Getting Started

1. Open the app and tap the menu (☰) in the top-left corner
2. Go to "Manage Dictionaries" to download your preferred dictionaries
3. Return to the home screen and start searching!

---

# Search

Use the two search boxes on the home screen:

- **Headword Search**: Find words as they appear in dictionaries
- **Definition Search**: Find words within explanations and definitions

Results appear in tabs, one for each active dictionary.

**Tip**: Tap on any word in results to search for it.

---

# Search Modes

Four matching modes are available:

| Mode | Description |
|------|-------------|
| **Exact** | Matches only the exact word |
| **Prefix** | Matches words starting with your query (default) |
| **Suffix** | Matches words ending with your query |
| **Substring** | Matches words containing your query anywhere |

You can set different modes for headword and definition searches.

---

# Managing Dictionaries

Access from the menu → "Manage Dictionaries"

- **Download** dictionaries you want to use (automatically enabled after download)
- **Enable/disable** dictionaries by tapping the toggle switch
- **Drag** to reorder priority (top = highest priority)

Only enabled dictionaries will appear in search results.

# Theme Options

Choose from the App Theme dropdown in Preferences:

- **Cologne**: Light blue theme matching the Cologne website
- **Light**: Classic light theme
- **Dark**: Dark mode for low-light use
- **Custom**: Create your own color scheme

---

# Siddhanta Font

The app uses the **Siddhanta** font for rendering Devanagari scripts. This ensures consistent display across all platforms, including iOS where system fonts may not support Vedic accent marks properly.

The font is applied automatically to:
- Headwords in search results
- Dictionary entry definitions
- Accordion list view headwords (when List Mode is enabled)

---

# Custom Theme Colors

When Custom theme is selected, you can customize:

| Color | Description |
|-------|-------------|
| **Primary Color** | App bar, buttons, links |
| **Background Color** | Main screen background |
| **Headword Color** | Words shown as headwords in definitions |
| **Sanskrit Text Color** | Sanskrit text within definitions |

Use the preset buttons to start with existing themes, then tweak the colors to your liking.

---

# Display Settings

- **Vedic Accents**: Show pitch accent marks (when available in dictionary)
- **Highlight Search Results**: Mark found terms in definitions
- **Maximum Results**: Limit how many entries to display

---

# Working with Results

- Use the **copy** button to copy an entry to clipboard
- Tap **"PDF"** to open the original source page
- Tap **"Correction"** to report errors to dictionary maintainers
- Close dictionary tabs with the **×** button

---

# Navigation

The side menu (☰) provides access to:

- **Home**: Return to search screen
- **Manage Dictionaries**: Download and organize dictionaries
- **Preferences**: Customize app settings
- **Help**: This user manual
- **About Us**: App information and contact details

---

# List Mode

List Mode displays search results as a collapsible accordion view, allowing you to browse multiple entries without navigating between pages.

- Toggle **List Mode** in Preferences
- Tap any entry to expand and view the full definition
- Tap again to collapse

This is useful for quickly scanning through many results.
