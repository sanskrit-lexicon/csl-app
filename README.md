# Cologne Sanskrit Lexicion App

This is a flutter project aimed at providing offline access to the Cologne Digital Sanskrit Lexicons.

## Features

1. Allows search within headwords and definitions.
2. Allows the user to search and get result in his / her preferred transliteration scheme.
3. User can download the dictionaries he wants and can also prioritize the order of dictionaries in the search results.
4. User can search with 'exact', 'prefix', 'suffix' or 'substring' searches.
